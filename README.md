## Status

Este repositorio sera mantido publico e arquivado como historico de evolucao do portfolio.

## Demo

[Acessar projeto online](https://my-portfolio-drab-kappa-69.vercel.app)

## Funcionalidades

- Apresentacao pessoal.
- Secao de projetos.
- Animacoes e elementos 3D.
- Tema claro/escuro.
- Layout responsivo.

## Stack

- **Next.js**
- **React**
- **TypeScript**
- **Three.js**
- **Motion**
- **Tailwind CSS**
- **Biome**

## Como executar

```bash
git clone https://github.com/marquesmaycon/my-portfolio.git
cd my-portfolio
npm install
npm run dev
```
